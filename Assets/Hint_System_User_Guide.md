# 🎮 暗号学習ゲーム - ヒントシステム完全ガイド

## 📋 ヒントシステムの概要

このゲームには、プレイヤーが暗号学習を効率的に進められるよう、包括的なヒントシステムが実装されています。

## 🎯 新しく追加されたUI要素

### **💡 ヒントボタン**
**場所**: 画面右上（ゲームプレイ画面）
**外観**: 黄色いボタンに「💡 ヒント」と表示
**機能**: クリックするとヒントシステムが起動

### **表示条件**
- ゲームシーン（Chapter_game.unity など）でのみ表示
- CryptoGameManagerが自動的に作成・配置
- Canvas上の右上位置（85%〜98%の範囲）に配置

## ⌨️ 操作方法

### **1. Hキーでヒント起動**
```
H キー を押す → ヒントシステム起動
```

### **2. ヒントボタンクリック**
```
画面右上の「💡 ヒント」ボタンをクリック → ヒントシステム起動
```

## 🔄 シーン切り替えの動作

### **ヒント起動時**
1. **現在のシーンを保存**
   - PlayerPrefsに元のシーン名を記録
   - カーソル状態を保存（ロック状態、表示状態）

2. **HintSceneに移動**
   - `SceneManager.LoadScene("HintScene")`
   - カーソルを表示・アンロック状態に変更

### **ヒントから戻る時**
1. **「メインゲームに戻る」ボタンクリック**
2. **保存されたシーン名で復帰**
   - 元のゲームシーンに戻る
   - カーソル状態を復元
   - PlayerPrefsのデータをクリア

## 🎨 ヒントシステムの構造

### **カテゴリ選択画面**
ヒント起動後、以下のカテゴリから選択：

```
🔐 共通鍵暗号      - AES、DES、鍵配送問題など
🗝️ 公開鍵暗号      - RSA、デジタル署名など  
🔗 ハイブリッド暗号  - SSL/TLS、暗号化の流れなど
🎮 ゲーム操作      - 移動方法、回答方法など
📚 一般ヒント      - 学習のコツ、セキュリティの重要性など
```

### **ヒント詳細表示**
各カテゴリで：
1. **ヒント一覧** - タイトル別のヒント項目
2. **詳細表示** - タイトル、内容、追加情報
3. **ナビゲーション** - 戻る、カテゴリ選択、ゲームに戻る

## 🎮 プレイヤー向け使用方法

### **基本的な流れ**
1. **ゲームプレイ中**
   - 問題がわからない時
   - 暗号の概念を確認したい時

2. **ヒント起動**
   - `H` キーを押す、または
   - 右上の「💡 ヒント」ボタンをクリック

3. **カテゴリ選択**
   - 知りたい内容に応じてカテゴリを選択

4. **ヒント確認**
   - 具体的なヒント項目を選んで詳細を確認

5. **ゲームに戻る**
   - 「メインゲームに戻る」で元の画面に復帰

### **便利な機能**
- **キーボードショートカット**: `H`キーで瞬時に起動
- **カテゴリ整理**: 内容別に分類された効率的なヒント
- **段階的詳細**: タイトル → 内容 → 追加情報の3段階
- **完全復帰**: 元のゲーム状態に正確に戻る

## ⚠️ 注意事項

### **シーン設定**
- HintScene.unityが必要
- RealHintSystemがHintSceneに配置されている必要

### **互換性**
- Unity 2023.2+ 対応
- 旧ヒントシステム（HintSceneTransition）との共存可能
- UIシステムの自動検出・作成
